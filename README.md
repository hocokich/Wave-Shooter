# Wave-Shooter
Итоговый проект в рамках курса UnitSkills.

## О проекте
Волновой шутер на Unity: игрок в закрытом помещении отбивается от врагов-примитивов.
В игре есть обратный отсчёт: по его истечении игра завершается.
Продлить игру можно убийством противников — за каждого убитого врага +5 секунд к таймеру.
Цель игры — протянуть как можно дольше.

## Геймплей
- Враги-примитивы спавнятся в заранее заданных точках (сериализованный список) и идут к игроку со случайной скоростью.
- Цвет врага зависит от скорости: медленные — зелёные, быстрые — красные, промежуточные — интерполяция.
- Контакт с игроком: `-5 HP`. Критическое HP — конец игры.
- HP врагов — `100`, урон игрока — `50`. Патроны у игрока ограничены.
- Враги через **Object Pool**, сохранения через **PlayerPrefs**, управление только через **Input System**.
- Если уровень здоровья игрока опустится до нуля игра завершится.

## Архитектура
- **Facade** — фасад игрока (стрельба, здоровье, input).
- **Observer** — события для UI и логики.
- **Object Pool**, **Input System**, **PlayerPrefs**.
- Разработка по **git-flow**.
